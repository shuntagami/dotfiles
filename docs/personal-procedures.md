# 本人から依頼された手続きで使う情報

- 引っ越し、住所変更、各種申請など、本人から依頼された手続きで氏名・住所・連絡先などが必要なときは、`~/dotfiles/private/personal-profile.md` を先に確認し、今回の入力に必要な情報だけ使う。今回本人が伝えた内容を優先する。不明な項目や変更の可能性がある項目は必要に応じて確認する。
- 本人確認書類が必要なときは、提出先の案内と本人の指示を確認してから `~/dotfiles/private/identity/` を参照する。マイナンバーや裏面は、提出先がその情報を明示的に求め、本人がその提出を依頼した場合に限り扱う。
- `private/` はこのMacのローカル保管先。実データをGitに追加したり、チャット、PR、共有資料、ログに転記したりしない。パスワード・暗証番号・ワンタイムコードは本人が入力する。
